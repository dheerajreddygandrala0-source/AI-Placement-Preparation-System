# Situational Interview

## Overview

Situational questions present hypothetical workplace scenarios and ask candidates how they would respond.

## Common Topics

- Conflict
- Deadlines
- Team problems
- Technical failures
- Customer issues
- Changing requirements
- Multiple priorities
- Ethical situations

## Common Questions

1. What would you do if you disagreed with your manager?
2. What would you do if you had a tight deadline?
3. What would you do if a teammate was not contributing?
4. What would you do if you discovered a serious bug before release?
5. What would you do if requirements changed suddenly?
6. What would you do if you did not know how to solve a technical problem?
7. What would you do if you had multiple urgent tasks?
8. What would you do if a customer was unhappy?

## Good Answer Approach

Candidates should demonstrate:

- Understanding of the situation
- Clear prioritization
- Communication
- Problem solving
- Professional judgment
- Appropriate escalation when necessary
- Learning from the outcome

# Software Engineer / SDE

## Role Description

A Software Engineer designs, develops, tests, debugs, and maintains software applications and systems.

## Core Skills

- Programming
- Data Structures and Algorithms
- Object-Oriented Programming
- SQL
- Database Management Systems
- Operating Systems
- Computer Networks
- Software Engineering
- Git and Version Control
- Problem Solving

## Common Programming Languages

- Python
- C++
- Java
- JavaScript

## Technical Interview Focus

Software Engineer interviews commonly assess:

- Programming fundamentals
- Data Structures and Algorithms
- Problem solving
- Object-Oriented Programming
- SQL and DBMS
- Operating Systems
- Computer Networks
- Project understanding
- Basic system design

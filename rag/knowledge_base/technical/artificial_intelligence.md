# Artificial Intelligence

## Overview

Artificial Intelligence focuses on building systems that can perform tasks that normally require human intelligence.

## Major Areas

- Machine Learning
- Deep Learning
- Natural Language Processing
- Computer Vision
- Robotics
- Expert Systems
- Generative AI

## Problem Solving

AI systems can use:

- Search algorithms
- Knowledge representation
- Reasoning
- Planning
- Optimization

## Search Algorithms

- Breadth-First Search
- Depth-First Search
- Uniform Cost Search
- Greedy Best-First Search
- A* Search

## Natural Language Processing

NLP focuses on processing and understanding human language.

Important concepts:

- Tokenization
- Stemming
- Lemmatization
- Embeddings
- Text classification
- Sentiment analysis
- Named entity recognition

## Generative AI

Generative AI systems can generate:

- Text
- Images
- Audio
- Code

Important concepts:

- Large Language Models
- Transformers
- Prompting
- Embeddings
- Vector databases
- Retrieval-Augmented Generation

## RAG

Retrieval-Augmented Generation combines information retrieval with language generation.

Basic flow:

1. User asks a question.
2. Relevant documents are retrieved.
3. Retrieved information is provided to the language model.
4. The model generates a response using the retrieved context.

# Deep Learning

## Overview

Deep Learning is a branch of machine learning that uses neural networks with multiple layers to learn complex patterns.

## Neural Networks

Basic components:

- Input layer
- Hidden layers
- Output layer
- Neurons
- Weights
- Biases
- Activation functions

## Activation Functions

Common activation functions:

- ReLU
- Sigmoid
- Tanh
- Softmax

## Training Concepts

- Forward propagation
- Backpropagation
- Loss function
- Gradient descent
- Learning rate
- Epoch
- Batch size

## Common Neural Network Architectures

- Feedforward Neural Networks
- Convolutional Neural Networks
- Recurrent Neural Networks
- LSTM
- GRU
- Transformers

## CNN

Convolutional Neural Networks are commonly used for image and spatial data.

Important concepts:

- Convolution
- Filters
- Feature maps
- Pooling
- Padding
- Stride

## RNN

Recurrent Neural Networks are designed for sequential data.

Common variants:

- LSTM
- GRU

## Transformers

Transformers use attention mechanisms to process relationships between elements in sequences.

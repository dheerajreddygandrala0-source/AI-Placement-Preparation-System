# Object-Oriented Programming

## Overview

Object-Oriented Programming is a programming paradigm that organizes software around objects containing data and behavior.

## Four Main Principles

### Encapsulation

Encapsulation combines data and methods inside a class and controls access to internal data.

### Abstraction

Abstraction hides implementation details and exposes only necessary functionality.

### Inheritance

Inheritance allows a class to acquire properties and behavior from another class.

### Polymorphism

Polymorphism allows the same interface or method to behave differently depending on the object.

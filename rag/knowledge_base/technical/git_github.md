# Git and GitHub

## Overview

Git is a distributed version control system used to track changes in source code.

GitHub is a platform for hosting Git repositories and collaborating on software projects.

## Important Git Concepts

- Repository
- Commit
- Branch
- Merge
- Clone
- Pull
- Push
- Remote
- Staging area
- Working directory

# Operating Systems

## Overview

An Operating System manages computer hardware and provides services for application programs.

## Core Concepts

- Processes
- Threads
- CPU scheduling
- Memory management
- File systems
- Input/output management
- Synchronization
- Security

## Processes

A process is a program in execution.

Important concepts:

- Process states
- Process Control Block
- Context switching
- Inter-process communication

## Threads

A thread is a lightweight unit of execution within a process.

## CPU Scheduling

Common scheduling algorithms:

- First Come First Serve
- Shortest Job First
- Round Robin
- Priority Scheduling

## Memory Management

Important concepts:

- Paging
- Segmentation
- Virtual memory
- Page faults
- Page replacement

## Synchronization

Important concepts:

- Mutex
- Semaphore
- Critical section
- Race condition
- Deadlock

## Deadlock

The four necessary conditions for deadlock are:

- Mutual exclusion
- Hold and wait
- No preemption
- Circular wait

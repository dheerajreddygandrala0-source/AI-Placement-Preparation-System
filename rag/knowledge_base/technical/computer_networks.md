# Computer Networks

## Overview

Computer Networks allow devices to communicate and exchange data over wired or wireless connections.

## Network Models

### OSI Model

Seven layers:

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

### TCP/IP Model

Common layers include:

- Network Access
- Internet
- Transport
- Application

## IP Addressing

- IPv4
- IPv6
- Public IP
- Private IP
- Subnetting

## TCP

TCP provides reliable, connection-oriented communication.

Important concepts:

- Three-way handshake
- Flow control
- Congestion control
- Reliable delivery

## UDP

UDP provides connectionless communication with lower overhead and no built-in guarantee of reliable delivery.

- Router

# System Design

## Overview

System Design involves designing software systems that are scalable, reliable, maintainable, and efficient.

## Important Concepts

- Scalability
- Availability
- Reliability
- Performance
- Maintainability
- Fault tolerance
- Security

## Scalability

### Vertical Scaling

Increasing the resources of a single machine.

### Horizontal Scaling

Adding more machines or instances.

## Important Components

- Load balancers
- Web servers
- Application servers
- Databases
- Caches
- Message queues
- APIs
- CDNs

## Databases

System design may involve:

- SQL databases
- NoSQL databases
- Replication
- Sharding
- Indexing

## Caching

Caching stores frequently accessed data closer to the application to reduce latency and database load.

Common caching systems include:

- Redis
- Memcached

## Message Queues

Message queues allow asynchronous communication between services.

Examples:

- Kafka
- RabbitMQ

## API Design

Important concepts:

- REST APIs
- HTTP methods
- Authentication
- Authorization
- Rate limiting
- API versioning

## Reliability

Important concepts:

- Redundancy
- Replication
- Failover
- Monitoring
- Logging
- Fault tolerance

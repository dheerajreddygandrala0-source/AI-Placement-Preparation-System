# Cloud Computing

## Overview

Cloud Computing provides computing resources such as servers, storage, databases, networking, and software through the internet.

## Service Models

### IaaS

Infrastructure as a Service provides virtualized infrastructure such as servers and storage.

### PaaS

Platform as a Service provides a platform for developing and deploying applications.

### SaaS

Software as a Service provides software applications through the internet.

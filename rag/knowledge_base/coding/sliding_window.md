# Sliding Window

## Overview

Sliding Window is used to efficiently solve problems involving contiguous subarrays or substrings.

## Types

### Fixed Window

The window has a fixed size.

### Variable Window

The window expands or contracts based on a condition.

## Problems

1. Maximum Sum Subarray of Size K.
2. Maximum Average Subarray.
3. Longest Substring Without Repeating Characters.
4. Longest Repeating Character Replacement.
5. Permutation in String.
6. Minimum Size Subarray Sum.
7. Minimum Window Substring.
8. Fruits Into Baskets.

## Common Techniques

- Frequency map
- Left pointer
- Right pointer
- Expand window
- Shrink window
- Maintain window condition

## Important Concepts

Sliding window can often reduce an O(n²) solution to O(n).

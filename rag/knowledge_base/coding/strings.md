# Strings

## Overview

String problems involve processing sequences of characters and commonly use hashing, two pointers, and sliding window techniques.

## Common Patterns

- Character frequency
- Two Pointers
- Sliding Window
- Hashing
- String traversal
- Palindrome checking
- Sorting characters

## Easy Problems

1. Reverse a String.
2. Check whether a string is a palindrome.
3. Count character frequencies.
4. Find the first non-repeating character.
5. Check whether two strings are anagrams.

## Medium Problems

1. Longest Substring Without Repeating Characters.
2. Longest Palindromic Substring.
3. Group Anagrams.
4. Longest Repeating Character Replacement.
5. Permutation in String.
6. String Compression.
7. Decode String.

## Hard Problems

1. Minimum Window Substring.
2. Word Break.
3. Regular Expression Matching.

## Important Concepts

- ASCII / Unicode characters
- Character frequency
- Palindromes
- Substrings
- Subsequences
- Anagrams

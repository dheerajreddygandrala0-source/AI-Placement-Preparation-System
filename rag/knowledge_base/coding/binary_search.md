# Binary Search

## Overview

Binary Search efficiently searches a sorted search space by repeatedly dividing it into two parts.

## Basic Pattern

1. Find the middle element.
2. Compare it with the target.
3. Eliminate half of the search space.
4. Continue until the answer is found.

## Problems

1. Binary Search.
2. Search Insert Position.
3. Find First and Last Position.
4. Search in Rotated Sorted Array.
5. Find Minimum in Rotated Sorted Array.
6. Find Peak Element.
7. Sqrt(x).
8. Koko Eating Bananas.
9. Capacity to Ship Packages Within D Days.
10. Median of Two Sorted Arrays.

## Advanced Pattern

Binary Search can also be applied to the answer when the search space represents possible answers.

## Important Concepts

- Sorted search space
- Lower bound
- Upper bound
- Search on answer
- Monotonic conditions
- O(log n) complexity

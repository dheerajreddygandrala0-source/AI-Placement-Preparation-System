# Dynamic Programming

## Overview

Dynamic Programming solves problems by breaking them into overlapping subproblems and storing previously calculated results.

## Two Main Approaches

### Top-Down

Uses recursion with memoization.

### Bottom-Up

Uses iterative computation with a DP table.

## Common Steps

1. Define the state.
2. Identify the recurrence.
3. Define base cases.
4. Compute and store results.
5. Return the required state.

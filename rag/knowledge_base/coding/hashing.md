# Hashing

## Overview

Hashing provides efficient lookup and is commonly implemented using hash maps and hash sets.

## Common Patterns

- Frequency counting
- Duplicate detection
- Complement lookup
- Prefix sum + hashmap
- Grouping
- Set membership

## Easy Problems

1. Two Sum.
2. Contains Duplicate.
3. Valid Anagram.
4. Intersection of Two Arrays.
5. First Unique Character.

## Medium Problems

1. Group Anagrams.
2. Longest Consecutive Sequence.
3. Subarray Sum Equals K.
4. Top K Frequent Elements.
5. Longest Substring Without Repeating Characters.
6. 4Sum II.

## Hard Problems

1. Minimum Window Substring.
2. Longest Duplicate Substring.

## Important Concepts

- Hash map
- Hash set
- Frequency map
- Average O(1) lookup
- Collision concept
- Prefix sums

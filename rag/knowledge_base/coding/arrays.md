# Arrays

## Overview

Arrays store elements in contiguous or indexed positions and are one of the most common structures in coding interviews.

## Common Patterns

- Traversal
- Prefix Sum
- Sorting
- Two Pointers
- Sliding Window
- Hashing
- Binary Search
- Kadane's Algorithm

## Easy Problems

1. Find the largest element in an array.
2. Find the second largest element.
3. Reverse an array.
4. Remove duplicates from a sorted array.
5. Move all zeroes to the end.
6. Find the missing number.
7. Find the maximum subarray sum.

## Medium Problems

1. Two Sum
2. Three Sum
3. Maximum Subarray
4. Product of Array Except Self
5. Merge Intervals
6. Rotate Array
7. Majority Element
8. Longest Consecutive Sequence
9. Set Matrix Zeroes
10. Spiral Matrix

## Hard Problems

1. Trapping Rain Water
2. First Missing Positive
3. Median of Two Sorted Arrays

## Important Concepts

- Time complexity
- Space complexity
- In-place modification
- Prefix sums
- Array traversal
- Subarray vs subsequence

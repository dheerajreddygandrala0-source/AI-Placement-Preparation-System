# Linked Lists

## Overview

A linked list consists of nodes where each node stores data and a reference to another node.

## Types

- Singly Linked List
- Doubly Linked List
- Circular Linked List

## Common Techniques

- Traversal
- Fast and slow pointers
- Reversal
- Dummy node
- Two pointers

# Heaps

## Overview

A Heap is a tree-based data structure commonly used to implement priority queues.

## Types

- Min Heap
- Max Heap

## Common Operations

- Insert
- Extract minimum
- Extract maximum
- Peek
- Heapify

## Problems

1. Kth Largest Element.
2. Kth Smallest Element.
3. Top K Frequent Elements.
4. Merge K Sorted Lists.
5. Find Median from Data Stream.
6. K Closest Points to Origin.
7. Task Scheduler.
8. Last Stone Weight.

## Important Concepts

- Priority Queue
- Min Heap
- Max Heap
- Heapify
- Top K problems
- O(log n) insertion/removal
